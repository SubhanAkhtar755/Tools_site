# 🤖 AI Tools Directory — React + Vite + Tailwind

A modern, responsive **AI Tools Directory Website** built using **React**, **Vite**, and **Tailwind CSS**.  
It showcases a curated collection of AI tools across multiple categories — from writing and design to coding, data, and productivity.

---

##  Live Demo

🔗 **Visit Website:** [https://tools-site-rebuilt.netlify.app](https://tools-site-rebuilt.netlify.app)

---

##  Pages Overview

###  Home Page
- Clean and minimal hero section introducing the platform  
- “Explore AI Tools” call-to-action  
- Brief description about categories and AI innovation  

###  AI Tools Page
- Displays a **curated list of AI applications**  
- Search bar for quick filtering by name or category  
- Categories include:
  - Audio/Video  
  - Chatbot  
  - Coding  
  - Data  
  - Design  
  - Image  
  - Marketing  
  - Productivity  
  - Writing  
- Responsive grid layout for seamless viewing on all devices  

###  About Page
- Overview of the project’s purpose and goals  
- Mentions the growing role of AI in creative and productivity fields  
- Highlights how this platform simplifies AI discovery  

###  Common Components
- **Header & Footer:** Reusable, minimalist components for navigation and consistency  
- **Search & Filter:** Built using React state for live category filtering
